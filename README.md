# Оцінювання кредитоспроможності підприємств

Вебзастосунок для введення фінансової звітності, автоматичного обчислення фінансових показників та оцінювання кредитоспроможності підприємств.

Користувач вводить дані **Балансу (Форма №1)** та **Звіту про фінансові результати (Форма №2)**, а система самостягує підсумкові рядки, розраховує 11 фінансових коефіцієнтів, переводить їх у функції належності й агрегує у підсумкову оцінку з присвоєнням кредитного рейтингу.

## Можливості

- **Введення звітності** — Форма №1 (рядки 1000–1900) і Форма №2 (рядки 2000–2650) у вигляді інтерактивних таблиць.
- **Автоматичні підсумки** — розрахункові рядки (підсумки розділів, баланс, валовий/чистий результат тощо) обчислюються «на льоту» і недоступні для ручного редагування.
- **Фінансові показники** — обчислення 11 коефіцієнтів `K1`–`K11`, згрупованих у три групи (ліквідність, ефективність, надійність).
- **Оцінка кредитоспроможності** — переведення коефіцієнтів у функції належності `uK1`–`uK11` та зважена агрегація у підсумкову оцінку.
- **Кредитний рейтинг** — інтерпретація підсумкової оцінки в рейтингову шкалу (від AAA до D) з кольоровою індикацією.
- **Збереження та історія** — звіти зберігаються в MongoDB; список збережених звітів доступний на сторінці.
- **Друк** — окремий стиль для друку дозволяє роздрукувати конкретний звіт.

## Технології

### Backend

## Методологія розрахунку

### 1. Фінансові показники

| Група  | Код | Показник                                                      |
|--------|-----|---------------------------------------------------------------|
| **G1** | K1  | Коефіцієнт миттєвої ліквідності                               |
|        | K2  | Коефіцієнт поточної ліквідності                               |
|        | K3  | Коефіцієнт загальної ліквідності                              |
|        | K4  | Коефіцієнт фінансової незалежності                            |
|        | K5  | Коефіцієнт маневреності власних коштів                        |
| **G2** | K6  | Коефіцієнт рентабельності виробництва                         |
|        | K7  | Коефіцієнт діяльності минулих років                           |
|        | K8  | Коефіцієнт найбільшої суми раніше повернутого кредиту         |
| **G3** | K9  | Термін існування підприємства                                 |
|        | K10 | Питома вага коштів підприємства у вартості кредитного проекту |
|        | K11 | Коефіцієнт наявності власного ліквідного майна                |

Показники розраховуються на основі рядків Форми №1, Форми №2 та додаткових даних (`V17`–`V22`).

### 2. Функції належності

Кожен показник `Kᵢ` переводиться у значення функції належності `uKᵢ ∈ [0, 1]` за відповідною функцією.

### 3. Агрегована оцінка

Підсумкова оцінка — зважене середнє функцій належності з нормованими ваговими коефіцієнтами:

```
ваги = [9, 8, 10, 7, 6, 8, 5, 7, 8, 6, 10]
```

### 4. Інтерпретація рейтингу

| Підсумкова оцінка | Рівень кредитоспроможності | Рейтинг  |
|-------------------|----------------------------|----------|
| > 0.57            | Найвищий рівень            | AAA, AA  |
| > 0.37            | Висока кредитоспроможність | A, BBB   |
| > 0.19            | Спекулятивний рейтинг      | BB, B    |
| > 0.11            | Можливий дефолт            | CCC      |
| ≤ 0.11            | Дефолт неминучий           | C, RD, D |

## Запуск проєкту

### Backend

```bash
cd backend
npm install
```

Створіть файл `.env` у `backend/`:

```env
MONGODB_URI=ваш_рядок_підключення_до_MongoDB
PORT=3000
```

```bash
npm run dev
```

Сервер за замовчуванням запускається на `http://localhost:3000`.

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Застосунок за замовчуванням доступний на `http://localhost:5173`.
